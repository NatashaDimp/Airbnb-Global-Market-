# 🏠 Airbnb Global Market Analysis

## 📊 Project Overview

This project presents an end-to-end analysis of the **global Airbnb market**, using data analytics and visualization techniques to explore pricing, availability, room types, geographical distribution, and listing activity across different markets.

The goal of the project is to transform raw Airbnb listing data into **meaningful business insights** that can help understand market characteristics, pricing patterns, customer accommodation preferences, and differences between Airbnb markets.

The project demonstrates my ability to work through a complete data analytics workflow — from preparing and analysing raw data using **Python** to developing an **interactive Tableau dashboard** that communicates insights in a clear and accessible way.

---

## 🎯 Business Objective

Airbnb operates across diverse markets, where pricing, accommodation types, availability, and listing activity can vary significantly.

The key objective of this project was to answer questions such as:

* Which markets have the highest Airbnb activity?
* How are Airbnb listings distributed geographically?
* Which room types are most popular?
* How does pricing vary across different markets?
* Which areas have higher concentrations of listings?
* How does availability differ between room types?
* What patterns can be identified from the Airbnb market data?
* What insights can be extracted to support data-driven decision-making?

# 🔍 Key Insights

The analysis provides several insights into Airbnb market behaviour.

### 1. Market Distribution

Airbnb listings are not distributed evenly across markets. Certain locations demonstrate substantially higher listing activity, indicating stronger Airbnb presence and potentially greater demand or tourism activity.

### 2. Room Type Patterns

Entire homes/apartments and private rooms represent important segments of the Airbnb market. The distribution of room types provides insight into the different accommodation preferences available to customers.

### 3. Pricing Differences

Average Airbnb prices vary considerably between markets and accommodation types. Location and room type are important factors when comparing pricing patterns.

### 4. Availability

Availability differs across listings and room types, providing an additional perspective on how properties are utilised within different markets.

### 5. Geographic Concentration

The geographic analysis highlights areas where Airbnb listings are more concentrated, making it possible to identify major Airbnb markets and compare their characteristics.
